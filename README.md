# 🌤️ Weather Forecast App

A simple, responsive weather forecast web app built with plain HTML, CSS and JavaScript. Search for a city and instantly see its current weather conditions.

## Features
- Search weather by city name
- Shows temperature, humidity, wind speed and weather condition
- Clean, responsive layout that works on desktop and mobile
- Error handling for invalid city names

## Tech Stack
- **HTML5**: page structure
- **CSS3**: styling and responsive layout
- **JavaScript (ES6)**: logic and API calls (Fetch API)
- **Weather API**: OpenWeatherMap (or the API you used)

## Project Structure
```
weather-forecast-app/
├── index.html
├── style.css
└── script.js
```

## Getting Started
1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/weather-forecast-app.git
   ```
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
3. Add your key in `script.js`:
   ```js
   const API_KEY = "YOUR_API_KEY";
   ```
4. Open `index.html` in your browser.
